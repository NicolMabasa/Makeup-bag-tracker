Glam Bag — Makeup Expiry Tracker

A web-based application that helps users keep track of their makeup products and receive timely reminders before those products expire — helping ladies protect their skin from the risks of using expired cosmetics.


About The Project

Expired makeup products can cause serious skin problems such as breakouts, irritation, rashes, and infections.
Many people are unaware that cosmetics have a shelf life and continue using them long after they've gone bad.
Glam Bag solves this by allowing users to log their makeup products along with their expiry dates.
The app then tracks these dates and notifies the user when a product is approaching expiry or has already expired — keeping your beauty routine safe and skin-friendly.


Features

Add and manage your makeup products
Track expiry dates for each product
Get notified about the state of the product ( good , about to expire and  expired )
View all your products in one organised place
Product category filtering (lips, eyes, face, etc.)



Built With

HTML & CSS — Structure and styling of the web interface
JavaScript — Frontend logic and expiry date calculations
Java — Backend logic and data handling

Getting Started

Prerequisites


A modern web browser (Chrome, Firefox, Edge)
Java Development Kit (JDK) installed for backend components


Running the Project

1 Clone the repository:
 * git clone https://github.com/NicolMabasa/Makeup-bag-tracker.git
2 Open index.html in your browser to launch the web interface.
3 To run the Java backend, compile and run the Java files:
* javac MakeUp.java MakeupProduct.java
* java MakeupProduct


Why This Matters
Using expired makeup is more common than people think.
Old mascara can cause eye infections, expired foundation can harbour bacteria, and outdated lip products can cause allergic reactions. 
Glam Bag empowers users — especially makeup lovers — to stay informed and make safer beauty choices every day.
